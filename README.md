# Aiselle Telegram Mini App

MVP интерфейса Айсель для Telegram Mini Apps.

## Запуск

```bash
npm install
npm run dev
```

Откройте http://localhost:3000

## Следующие этапы

1. Подключить официальный Telegram Web Apps SDK.
2. Создать Telegram Bot через BotFather.
3. Указать HTTPS URL Mini App.
4. Проверять Telegram initData на сервере.
5. Подключить PostgreSQL.
6. Подключить AI API через сервер.
7. Добавить Telegram Stars.
8. Добавить память диалога и лимиты.
